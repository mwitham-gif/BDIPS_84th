# BDIPS 84th Street Resource Guide

Community resource directory for Better Days Integrated Programs (BDIPS), serving residents and neighbors around 238 84th St, Los Angeles, CA 90003.

This repository is being set up. The site will be a static, mobile-first, bilingual (English and Spanish) directory backed by a Google Sheet, built from the same code as the Community Corporation of Santa Monica resource guide (https://github.com/mwitham-gif/CCSM).

Status: initial setup. See the pull requests for progress.
